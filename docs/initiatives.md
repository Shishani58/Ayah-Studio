# User initiatives

Журнал продуктовых/алгоритмических инициатив пользователя. Новые инициативы
добавлять сюда, чтобы не терять направление работы между task-файлами.

## 2026-06-28 — Fast без fallback

- Не лечить плохой fast-алгоритм fallback-режимами (`full`/`tiled`).
- Если fast ошибается или ставит `drift_detected=True`, это диагностировать и
  исправлять внутри fast.

## 2026-06-28 — Слоистый поиск пауз

- Найти все pause-кандидаты и разделить их по достоверности.
- Основной проход делать по достоверным паузам.
- Если по чтению после паузы видно, что алгоритм перескочил через аят,
  вернуться в пропущенный интервал и искать среди менее достоверных пауз.
- Менее достоверные паузы не должны ломать нормальный проход: подключать их
  локально, только когда есть доказанный пропуск.

## 2026-06-28 — Не идти вперёд при неясном декоде

- Если следующая пауза декодировалась не как ожидаемый текущий аят, fast не
  должен молча переходить к следующему аяту.
- Сначала нужно определить, что слышно в этой точке: текущий, прошлый, будущий
  аят или шум/внутренняя пауза.
- После локализации разрешены только явные действия: вернуться к пропущенному
  интервалу, сдвинуться к реально услышанному будущему аяту, или запустить
  локальный поиск/wasl для текущего места.
