# python-style.md — стиль кода

- Python ≥3.10. Type hints обязательны для публичных функций/методов.
- Форматирование/линт — `ruff` (line-length 100). Без неиспользуемых импортов.
- Ядро (`core/`, `data/`) — **чистый Python без GUI**: тестируемо и
  переиспользуемо CLI и GUI. Никаких импортов PySide6 в `core/`/`data/`.
- Никакой тяжёлой работы в UI-потоке: декод/инференс — в worker-потоке/процессе,
  прогресс — через сигналы.
- Чистые функции там, где можно (вход → выход без скрытого состояния); побочные
  эффекты (запись БД, I/O) — изолированы в `data/`.
- Тесты под `tests/`, `pytest`. Для багов с тестируемым швом — регресс-тест в том
  же изменении.
- Минимализм зависимостей (см. CLAUDE.md «Минимализм»). Помечать сознательный
  компромисс `# shortcut:` + путь апгрейда.
- Сообщения/комментарии — кратко; код самодокументируемый.
