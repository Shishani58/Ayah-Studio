# Контракт измерений (до новых результатов)

Исторический sparse12 — только источник гипотез. Fresh baseline-a2 использует
замороженную текущую копию; baseline-a — сохранённая ошибка отсутствия весов,
не нулевой результат модели. Production snapshot sparse12 побайтово совпал
с исходниками текущей копии (historical-source-diff.json).

Корпус A: Шатри 1,2,32,55,59,65,73,77,79,80,98,112, четыре модели.
Разработка: bootstrap80/98/112, успешное1:1, известный отказ1:2 только контроль.
Другой чтец разработки — Гамиди80/98/112 (уже изученный regression).
Подтверждение после freeze: Миншауи/Хусари80/98/112; отдельный stress:
Абдуль-Басит mujawwad80/98/112. E/F обязательны при общем изменении;
если production не меняется, не выдавать identical before/after за улучшение.
Файлы и SHA закреплены data-manifest.json до просмотра новых результатов.

H1: новый word/connected диагностический опыт на80/98/112; существующие
1:2 normalization/quantization и pre-roll опыты не повторять как новые гипотезы.
H2: статический аудит114 сур/реального vocab; изменение только при документированной
несовместимости, симметричной для rivals. Никакой подстановки из decode.
H3: first-entry versus локальное позднее вхождение на тех же разрешённых frames;
максимум по offsets сам не является нормированной вероятностью события.
H4/H6: новые действия только по обнаруженному сильному cue/полной фразе,
без сканирования. H5: не менять representation/tempo без выявленного различия.
H7: независимые onset/previous-end/playback interval labels отсутствуют;
подготовить пакет без выдуманного слушателя. Старые midpoint/heads не повторять.
H8: независимый dispatch/ledger, реальные imports, tree RSS sampling200ms.

Подтверждения = confidence>0 с принятым validator proof. Review estimates
не являются ошибками acoustic model. Primary stop — первое RESOLVE_BLOCK или
REVIEW_REQUIRED; недоступный хвост после него — потенциальный каскад, не множество
независимых локальных отказов. Реализованный прирост измеряется парно по строкам.
Reference читается bench только после всех predictions. Ошибка к нему отличается
от физической точности. Identity-only и cue не создают время.

Стоимость: действительные calls/samples/PCM/outcomes/cache/union/sum, фазы
decode/DSP/load/inference+matcher; текущий runner разделение inference/matcher
получает из read.seconds и total. RSS — одновременная сумма живого дерева,
200ms sampling, возможны пропущенные короткие пики. Ускорение по одному wall
не заявляется. При кандидате нужны три одинаковых warm paired repeat.

Все attempts получают отдельный ID, команду, stdout/stderr/exit, source root,
PCM coordinates/hash, наблюдение и решение. Не перезапускать живой процесс.
Все модельные чтения через общий ledger6s/65%/200%, cache32MiB.
