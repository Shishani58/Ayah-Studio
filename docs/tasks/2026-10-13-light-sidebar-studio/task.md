(просмотрен); заменяет прежнюю компоновку.
Скоуп: HTML/JS/CSS UI; единая шапка, sidebar с поиском/реальными статусами,
сводка над волной, светлые нейтральные поверхности, графитовая волна,

логи, генерация/отмена, SSE и режим слов сохраняются.

обработчики/render/stream/темы. Причина: не затереть новые настройки/логи/SSE.
Решения: только UI, отдельный CSS слой; номера/число/текст из API/канонической
БД. Сура без аудио недоступна; partial не означает verified; цвет аятов —
existing status, без придуманной confidence. Новая метрика не вводится.
Боковой поиск по номеру/названию; компактный номер с двумя строками справа.
Названия: проверить metadata источник, БД канонического текста названий не
содержит. Текст Корана и пользовательские файлы не меняются.
