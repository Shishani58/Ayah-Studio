# Copy visible logs

## Скоуп

Добавить в web GUI возможность копировать отображаемые live-логи генерации.
Не менять пайплайн генерации, формат БД и сохранение логов на диск.

## Решения

- Копировать именно текст из видимого блока логов, без запроса к серверу.
- Использовать Clipboard API с fallback через `execCommand`, чтобы работало и в pywebview/браузере.
- Кнопку держать disabled, пока в логе нет строк.
