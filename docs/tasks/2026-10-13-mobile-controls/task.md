# Мобильное оформление элементов управления

Цель: убрать резкие/разорванные выделения поиска, группы кнопок и закрытия;
сделать меню действий и элементы управления похожими на мобильный интерфейс.
Скоуп: существующие HTML/CSS/JS, без изменения API и разметки Корана.
Прочитано: RTK.md, web-ui-ux, better-ui, better-accessibility; текущие стили,
обработчики focus/menu, STATUS.md и задачи studio/settings — для сохранения
существующих функций и адаптивности. AGENTS.md/CLAUDE.md идентичны.
Решения: мягкие поверхности вместо рамок; клавиатурный focus сохранён,
при pointer/autofocus кольца скрыты; меню — группы строк, на узком окне
нижняя панель. Работа поверх имеющихся пользовательских изменений.
