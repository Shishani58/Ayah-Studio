# Улучшить UI/UX экрана ревью

## Скоуп
Входит: компоновка web-GUI ревью, читаемость панелей управления, статус ошибок,
волна и список аятов. Не входит: алгоритмы выравнивания, API, формат БД.

- docs/project.md — пропущен: архитектура пайплайна и формат БД не меняются.

## Решения
- Разделить верхнюю панель ревью на навигацию, действия с сурой и плеер, чтобы
  элементы не вылезали за край окна.
- Держать ошибку/статус в отдельном компактном блоке, не как элемент в одной
  строке с кнопками.
- Улучшить плотность списка аятов без изменения текста Корана.
