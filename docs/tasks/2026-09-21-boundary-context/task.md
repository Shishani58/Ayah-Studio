## Диагностика и отклонённые варианты

- Исходная сура 2 воспроизведена: median 72, p90 431, max 20692 мс;
  pause/sequence OK, emission_passes=1. Все 213 исходных тестов проходят.
- Базовые trace/log и экспериментальные полные результаты сохранены в
  `/tmp/surah-boundary-context/`; акустические frames одного полного прохода
  сохранены для повторной проверки решений без повторного вызова модели.
- Простое включение всех внутренних повторов расширяло уже достаточное чтение
  и ухудшало 2:9. Теперь расширяется только реально недостаточный префикс.
- Неограниченное разделение чтения могло взять паузу предыдущего аята, а
  неполный CTC-путь после padding выглядел высокоуверенным. Для нового решения
  введены полный путь и исключение паузы предыдущего владельца.
- Короткие частицы остаются в CTC-тексте; оценка фразы взвешена по буквам,
  последнее различающее слово обязательно. Слабое распевное первое слово
  допускается только с сильной паузой, доказанным предыдущим хвостом и отдельным
  различающим бюджетом последующей фразы.
- Ложный перенос 2:235 выявил сжатие предыдущего текста CTC перед внутренней
  паузой. Greedy-декод после спорного начала сравнивается отдельно с текущей
  фразой и окончаниями предыдущего аята; преимущество предыдущего текста
  запрещает перенос. Проверка с этим ограничением меняет только четыре
  целевые границы и улучшает их до 639/30/42/56 мс.
- Дополнительно проверяются оставшиеся ранние выбросы 2:120/220 (>2 с).
  Перенос вперёд требует, чтобы старая метка лежала в подтверждённом хвосте
  предыдущего аята, и независимый decode предпочитал этот хвост. Одной CTC
  confidence недостаточно: такой вариант давал регрессии на 78/83/98.
