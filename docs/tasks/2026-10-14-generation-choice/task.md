канонического текста, FAST или схемы БД.

Решения:
- Явный выбор пользователя разрешает перезапись; без него default сохраняет
  edited/verified. Старый force=True остаётся запрещённым.

  строки атомарно, с историей старого/нового времени и проверкой порядка.
- Один диалог для текущей суры и пакетного Start; RU/EN, отмена/Escape,
  начальный фокус на сохранении ручных меток, возврат фокуса.
