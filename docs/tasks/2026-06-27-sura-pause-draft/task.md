# Черновая разметка суры по паузам

## Цель

Упростить экран суры: убрать отладочные кнопки VAD/TEN/DSP/fast-log и добавить
практичный поток работы:

- вручную ставить старт текущего аята по позиции на волне;
- черново разметить суру по паузам/тишине с учётом числа аятов и темпа;
- запустить корректировку черновика, не затирая `edited`/`verified`.

## Скоуп

- Web-GUI экран суры (`webgui/static/index.html`, `app.js`, `style.css`).
- API web-GUI (`webgui/server.py`).
- Небольшой core-модуль для черновой разметки по паузам.

## Прочитанные документы

- `AGENTS.md`: обязательные правила, особенно task-файл и запрет затирать ручную
  разметку.
- `docs/project.md`: инварианты БД, число аятов, смысл тайм-кодов.
- `docs/STATUS.md`: текущее состояние web-GUI, fast/VAD/TEN и перепроверки.

## Решения

- VAD/TEN остаются внутренними инструментами алгоритма, но их кнопки убираются с
  экрана.
- Черновая разметка пишет только `auto`; `edited`/`verified` остаются якорями и
  не перезаписываются.
- Корректировка использует существующий точный пайплайн (`tiled`) как исправляющий
  проход и пишет результат через обычный merge, поэтому ручные правки защищены.
