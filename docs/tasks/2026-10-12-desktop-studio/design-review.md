# Ревью десктопной студии

## Scope и coverage
Путь: импорт проекта → выбор записи/суры → ревью аятов → правка времени →
настройки. HTML/JS + CSS, FastAPI, существующие цветовые токены и QPC Hafs.
Правила: AGENTS.md/CLAUDE.md и docs/project.md. Пословный pipeline,
диагностические таблицы пауз и нативные файловые диалоги отдельно не аудировались.

| Domain | Evidence inspected | Result |
| --- | --- | --- |
| Accessibility | index.html:280 (dialog); app.js:691 (строки); AX tree, Up/Enter/Tab/Escape, сохранение фокуса | Устранены проблемы имён кнопок и клавиатурной правки |
| Layout | style.css:547, 587; экраны 1280×720, 1536×1000, 320×900 | Одинаковый правый край RTL; без горизонтального overflow |
| Writing | app.js:35, 1071, 1191; импорт и ошибка пересечения меток | Формат времени и путь исправления явны |
| Typography | QPC Hafs из БД, exactTime, tabular-nums, настройки 30/36px | Текст не подменяется, время до миллисекунд |
| Colors | Реальные computed styles текста/фона; измеренные пары ниже | Проверенные пары проходят AA |
| UI | studioIcon, hover/selected, modal, wave/list, empty/loading/error | Удалены боковые панели и значки в аятах; единые SVG плеера |

## Verification
- `pytest -q`: 291 тест проходит, в том числе импорт копий, сохранение
  verified/history, смена проекта, ошибка записи настроек и пересечение границ.
- `ruff check .`, `node --check surah_cutter/webgui/static/app.js`,
  `git diff --check`: чистые.
- Реальный local FastAPI + браузер: создан временный проект с двумя WAV;
  импортирована копия временной SQLite; правки +10мс/+50мс сохранились после
  повторного открытия. Up сохраняет фокус; Enter с 00:00.000 для третьего аята
  отклонён, прежняя метка восстановлена; последующая правка убирает ошибку.
- Настройки шага и размера текста сохраняются; Escape закрывает dialog и
  возвращает фокус. Узкое окно: documentWidth=320, dialogWidth=286,
  dialogScrollWidth=284. Большое окно: documentWidth=1536.
- Контраст: основной текст/bg 16.06:1; muted/panel 6.64:1;
  текст input/panel2 13.35:1; saved/panel 6.14:1; focus/panel2 10.98:1.
- Скриншоты: studio.jpg и settings.jpg — работающий UI, не ImageGen.

**Not verified:** полноценный VoiceOver-прогон, настоящий браузерный zoom 200%,
нативное окно pywebview на Windows, качество выравнивания реального чтения,
полный импорт коллекции 114 аудиофайлов и оценка места на диске.
Для UI-проверки использован синтетический WAV; пользовательские данные не редактировались.

## Verdict
Approve для указанного пути и проверенных состояний. HIGH-находок в нём не осталось.
Это не подтверждение native/VoiceOver/200% zoom и не аудит pipeline выравнивания.
