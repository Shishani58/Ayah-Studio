# Открытие суры без ожидания волны

Цель: сразу показать экран ревью, независимо загрузить аяты, волну и аудио.
Скоуп: web GUI; без изменений БД, текста Корана и пайплайна.
Прочитано: AGENTS.md/CLAUDE.md (политика), docs/STATUS.md (текущий интерфейс).
Решение: отдельные состояния загрузки и ошибки, защита от устаревших ответов,
недоступные до готовности действия. Существующие изменения пользователя сохранены.

- [x] Реализация
- [x] Проверка задержек, ошибок и переключения сур в браузере
- [x] Синтаксис JS, релевантные тесты, diff check

Блокеры: нет.

Проверка: `verify.cjs` — Chrome через Playwright, API с управляемыми задержками:
сразу видимый экран, независимые аяты/аудио/волна, ошибки каждого блока и повтор,
устаревшие ответы при переключении/возврате, загрузка/ошибка слов, aria-busy.
Визуально проверены 1180×900 и 390×844. Реальные длинные аудиофайлы не измерялись;
проверка подтверждает поведение интерфейса при задержках, не ускорение декодера.
`pytest -q tests/test_webgui_server.py tests/test_webgui_launch.py`: 21 passed.

с NODE_PATH на Playwright из bundled runtime. Требуется установленный Chrome.
