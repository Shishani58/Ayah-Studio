# Регулировка скорости воспроизведения

Цель: повторить поведение примера, сохранив оформление приложения.
Скоуп: HTML/JS/CSS плеера; без изменения разметки и данных.
Прочитано: RTK, web-ui-ux, актуальные разделы STATUS, wire,
updateRatePicker, openReview, scheduleWordStop и клавиатурные обработчики.
Решения: нативный range 0,2–2 с шагом 0,05; пресеты 0,5/0,8/1/1,5/2.
Изменение применяется на input без остановки/перемотки. Меню остаётся
открытым после выбора; Escape и клик снаружи закрывают его.
Скорость сохраняется при переключении суры через defaultPlaybackRate.
