# Wave and log layout

## Цель

Сделать лог суры нижней панелью поверх списка аятов с изменяемой высотой и
кнопкой полного скрытия. Упростить масштаб волны: убрать верхний слайдер,
добавить pinch-zoom двумя пальцами и кнопки перехода к началу/концу волны.
Начальный масштаб подобрать адаптивно по длине суры.

## Скоуп

- Web GUI review screen.
- Только разметка/стили/клиентский JS.
- Без изменения формата БД и pipeline.

## Прочитанные доки

- `docs/tasks/2026-06-28-realtime-sura-logs/task.md` — прочитан: откуда берется
  realtime-лог суры и как он отображается.

## Решения

- Лог оставить тем же `suraLiveLog`, но перенести в конец review-секции, чтобы он
  перекрывал нижнюю часть списка аятов через `position: absolute`.
- Высоту панели менять CSS `resize: vertical`; скрытие делать классом на review.
- Pinch-zoom обрабатывать через `wheel` с `ctrlKey` и через Pointer Events для
  двух касаний внутри горизонтального scroll-контейнера.
- Начальный масштаб считать из длительности и числа аятов: целевой видимый
  диапазон около 45 секунд, но с учетом средней длины аята и ограничениями.
- Доработка: браузерный `resize` для нижнего absolute-блока неудобен, поэтому
  высота лога меняется явной верхней ручкой через Pointer Events.
- Доработка: кнопки начала/конца размещены по бокам самой области волны.
- Доработка: стартовый zoom усилен до потолка `100x`, с видимым диапазоном
  примерно 35-80 секунд.
