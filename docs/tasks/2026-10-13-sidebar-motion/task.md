## Уточнение: синхронное расширение и кнопка над основной областью

По снимку пользователя кнопка должна начинаться на уровне основного экрана
с его левым отступом. Шапка получает группу бренд/sidebar шириной колонки.
Панель и основная область меняют ширину одновременно. Для этого узкого
layout-перехода анимируется ширина оболочки; содержимое остаётся фиксированной
ширины и уезжает transform. Это необходимое исключение из рекомендации
animate о transform-only для явно запрошенного синхронного изменения layout.
Плеер и шапка двигаются с той же длительностью; canvas обновляется по кадрам.
На узком экране панель остаётся overlay.

Проверки уточнения: Chrome 1440/820/390/320 px, оба направления,
прерывание, inert, reduced motion, отсутствие JS ошибок. На desktop кнопка
начинается в 18 px от основной области; на промежуточном кадре ширина sidebar
равна координате левого края основной области, обе меньше исходной ширины.
Desktop-снимок просмотрен. Node --check и diff-check прошли.
WKWebView и готовая сборка не проверены; блокеров нет.
