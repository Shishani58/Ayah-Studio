# Достоверность времени начала

Цель: проверяемый процент попадания в ±500 мс относительно принятого начала/разреза; очередь ручного ревью.

Scope: чтение сохранённых диагностик, независимый аудит переноса калибровки, оценка неоднозначности разреза, UI фильтр/сортировка. Времена и ручные статусы не меняются. FAST без дополнительных модельных чтений.

Прочитано: AGENTS.md/CLAUDE.md, RTK.md; docs/project.md и STATUS.md (контракт pipeline и история); confidence-evidence/report.md и audit.py (неудача уровней); full-local-pause/comparison.json (парные метки); fast-systematic-execution/annotation-protocol.md (пустая независимая разметка, неизвестная семантика reference); web-ui-ux/SKILL.md (существующий web GUI).

Решения: акустические scores не проценты времени; reference agreement отдельно от физического onset. Прежде публикации процентов необходимы независимые временные метки и held-out проверка по записям. Длинная пауза даёт неоднозначность выбранного разреза даже при подтверждённой принадлежности.
