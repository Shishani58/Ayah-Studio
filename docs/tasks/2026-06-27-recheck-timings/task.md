# Режим перепроверки тайм-кодов (recheck) + отдельная кнопка

## Цель / скоуп
Дать ревьюеру кнопку «перепроверить»: пройтись по **уже сделанным** тайм-кодам
суры и проверить их корректность — без перегенерации и без правок БД.
Только аудит и подсветка подозрительных аятов; правит человек вручную.

Скоуп: per-sura, на экране ревью. Read-only (не пишем timings/status).
Вне скоупа: автоисправление, whole-project проход, изменение статусов.

## Прочитанные доки/код и почему
- `core/align.py` — примитивы эмиссий (`_emissions`, `_stride_ms`, `ALIGN_LAG_MS`,
  bundle/vocab). Источник эмиссий для greedy-decode.
- `core/align_fast.py` — уже есть нужный сигнал: greedy-decode в точке + `_sim`
  с ожидаемым началом аята (placement-verify-sim, fallback `_VERIFY_SIM`).
  Переиспользую `_default_bundle`, `_sim`.
- `webgui/server.py` — паттерн эндпоинтов `/api/sura/{n}/...`, чтение timings
  (`_sura_timings_reviews`).
- `webgui/static/{index.html,app.js,style.css}` — экран ревью, `renderAyahList`,
  `drawWave`, состояние `R`, `wire()`.
- Память: [[fast-mode-failure-landscape]], [[alignment-validated]] — абсолютный
  sim шумный (путается с васл-плотностью); относительное сравнение с соседями
  (off-by-one) надёжнее.

## Решения
- **Сигнал**: для каждого аята с временем `t` — greedy-decode `[t-50, t-50+2500]`
  и `_sim` с началом аята (первые 4 слова). Это «что реально слышно тут».
- **Вердикт** устойчивее абсолютного порога за счёт сравнения с соседями ±2:
  - `shift` — у соседа `j` совпадение выше своего на маржу → «звучит как аят j»
    (типичный off-by-one дрейф);
  - `ok` — своё совпадение ≥ `_OK_SIM` и никто не лучше;
  - `weak` — низкое своё совпадение и нет лучшего соседа (васл/смещение → глянуть).
- **Один проход эмиссий** по суре (как full-align), per-ayah — дешёвые срезы
  кадров. Память: записка fast-landscape — per-window overhead дороже одного
  полного прохода; целостно с full-режимом.
- **Read-only**: не трогаем БД → не нарушаем «не затирать ручную разметку» и
  «.db руками не правим в обход кода». Пороги env-tunable для калибровки.

## Калибровка (решающая, на эталоне Шатри)
Прогон recheck на ЗАВЕДОМО КОРРЕКТНЫХ таймкодах (эталон) + на искусственно
испорченных. Сводка (суры 112, 78):
- **корректные** → `shift`=0 (ноль ложных). Абсолютный порог `weak` фолзил
  18/40 (45%) корректных аятов — sim корректных 0.14–0.78, НЕразделим.
- **off-by-one** → 30–31/40 `shift`, каждый указывает на верного соседа.
- **+4с/+8с дрейф** → 20/26 `shift`. **локальный +5с на 10–15** → ровно
  `[11,12,14,15]`, без ложных вне зоны.
→ **Вывод**: убрал абсолютный `weak`, вердикт чисто относительный (`ok`/`shift`),
маржа 0.10. Совпадает с памятью [[fast-mode-failure-landscape]]: чистого
GT-free абсолютного детектора нет; относительный — единственный надёжный.
