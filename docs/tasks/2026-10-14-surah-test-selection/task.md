# Подбор сур для регрессионных проверок

Цель: сравнить все 114 сур по интервалам между аятами и текстовой структуре;
предложить небольшой набор коротких записей для FAST/FULL. Production и БД
не изменяются. Нельзя обещать 95% выявления ошибок по сходству признаков.

Прочитано: AGENTS.md/CLAUDE.md и RTK.md (правила); разделы docs/project.md
о формате начала аята и FAST; релевантные записи docs/STATUS.md и задачи
full-pause-windows/tarteel-tiny-fast (аудио и имеющиеся регрессии).
Serena: references.validate (проверки эталонов). pages:write-page — оформление
локального отчёта с сохранением проектного формата.

Решения: только readonly SQLite; интервалы start→next start включают паузы;
последние аяты не восстанавливаются из эталонной БД; общая длительность
Аш-Шатри берётся из существующего PCM-каталога. Сходство не включает общую
длину записи. Текст нормализуется только в памяти для сравнения.

Результат: основной набор 1/32/55/59/65/73/77/80/98/112, 275 аятов,
2703.752 с аудио Шатри. Представлены 8 рассчитанных структурных групп и
4 диапазона длительности. Расширенный набор — 15 сур/336 аятов/3082.816 с.
Полные группы и ограничения — groups.md/report.md. Примеры пользователя
не используются как критерий выбора; отдельные сравнения этих пар удалены.

Проверка: два последовательных расчёта дают побайтово одинаковые JSON/CSV
и groups.md. Проверены 114 сур/6236 аятов, 29 сур с начальными буквами,
разбиение без пропусков/дубликатов, матрица расстояний 114×114, симметрия,
нулевая диагональ, представительство 8/4 групп. SHA256 всех БД и исходного
каталога PCM-длительностей совпали до/после; Ruff и diff-check прошли.

Ограничения: новых модельных прогонов нет; 95% выявления регрессий не
подтверждено. Внутренние акустические паузы/wasl не исследованы. Фрагменты
длинных сур предложены, но не нарезаны. Полные длинные прогоны остаются
нужны для накопления drift и глобальных бюджетов/склейки/памяти.

Пользователь согласовал набор и попросил закрепить в документации.

случаев; архитектура, пайплайн, production и формат БД не изменены.
