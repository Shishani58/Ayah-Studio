# FULL: целостность границы и сравнение моделей

## Цель

Исправить реальные времена FULL, начиная с Фатихи, и сравнить QPC INT8 с
Muaalem на сохранённых ошибках и хороших контролях. Улучшение числа флагов
само по себе не считается исправлением. Не менять текст, число/порядок аятов,
edited/verified, FAST; не коммитить/пушить. Чужие изменения сохранить.

## Прочитано

AGENTS/CLAUDE,RTK,project,STATUS,full-performance иfull-accuracy report/JSON:
контракты, previous evidence, замороженные аудио/GT/matrices. align/checker,
CTC, RuntimeEmitter иmodel_worker: FULL время из forced path/attention DTW,
ASR token probability не доказывает timestamp. Default-флаги слабого префикса
не ловятФатиху1:2 (сильныйa до паузы, сильныйl после неё).

## Решения

- Эталон только для оценки после предсказаний; без fit поаятах/временамGT.
- Независимое локальное ASR конца предыдущего/начала следующего аята для
  диагностики принадлежности звуков. Не называть это человеческим прослушиванием.
- Freeze runtime comparison до правок; reused matrices отдельно от fresh inference.
- Результат кандидата проверить на всех контролях и крупные новые ошибки
  сохранять, а не скрывать aggregate метрикой. Default не менять до сравнения.
