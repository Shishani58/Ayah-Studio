# Цветные сегменты статуса слов

Цель: перенести систему статусов аятов в пословный режим; по уточнению
пользователя карточки должны быть компактными, время и сегменты открываются
по номеру слова в меню, текст слова остаётся кнопкой прослушивания.
Скоуп: карточки слов, запись статуса существующей метки через word edit API;
формат БД/текст/алгоритмы выравнивания не меняются.
Прочитано: renderWords/editWord, word edit API, ProjectDB.verify_word,
set_word_time и пословный контракт docs/project.md.
Решения: те же цвета и подписи; сброс сохраняет время; edited/verified
защищены от пересчёта. Устаревшую метку нельзя отметить актуальной сменой
статуса: сначала обновление времени, затем статус.
