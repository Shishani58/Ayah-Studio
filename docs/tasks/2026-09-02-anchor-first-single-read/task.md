# Anchor-first FAST с одним чтением emissions

## Цель

Перестроить FAST вокруг разреженного каркаса достоверных pause-owner и
локального заполнения промежутков. Каждый участок аудио должен проходить через
акустическую модель emissions ровно один раз; повторные текстовые гипотезы и
forced alignment используют сохранённые frames.

## Скоуп

- одно полное windowed-emissions чтение суры и только frame-срезы после него;
- минимальный текстовый объём чтения: не только первое уникальное слово, а
  настраиваемый минимум букв/слов с расширением до различия текущего и
  следующего/повторяющегося начала;
- высокоточный anchor-first каркас над pause-кандидатами;
- заполнение промежутков существующим последовательным/wasl align без повторной
  акустической инференции;
- trace, unit/regression tests и реальные benchmark-прогоны.

## Решения

- «Одно чтение» означает один вызов генерации emissions для полной PCM суры;
  внутренние 30-секундные окна модели являются одним детерминированным проходом.
- Текстовые сравнения, greedy decode и локальный forced alignment могут
  выполняться повторно только над уже готовыми frames.
- Anchor имеет высокий порог precision и не заменяет порядок аятов; gaps
  разрешаются локально, а wasl остаётся полным чтением текста между опорами.
- Сначала сохраняются действующие алгоритмы gap-resolution и инварианты; новый
  каркас меняет координацию, а не арифметику меток.

## Результат

- Акустическая сложность стала O(T) с одним проходом вместо повторной обработки
  перекрывающихся окон. На суре 2 время снизилось с 1361.0 до 527.1 с (2.58x),
  а относительно предыдущего one-pass результата 551.5 с — ещё на 4.4%.
- Anchor scan и sequential matcher имеют раздельные decode-cache; очистка между
  ними не повторяет ONNX inference.
- Подтверждённые anchors делят поиск на независимые gaps. Будущий anchor задаёт
  только правую границу набора пауз и не меняет prior левого gap.
- Если две близкие pause-гипотезы указывают на одну пропущенную границу,
  ограниченный gap решается совместно по всему порядку пауз/аятов. Короткие
  начала используют широкое чтение, уже полученное из сохранённых frames;
  выбранный последовательностью pause-owner нельзя перезаписать локальной
  эвристикой с меньшим контекстом.
- Спекулятивная локальная перепроверка `pause_fallback` отклонена: на суре 2 она
  перезаписывала корректные соседние границы. Повторный локальный align разрешён
  только при явном `insufficient_audio`.
- Документация обновлена: `docs/project.md`, `docs/STATUS.md`, этот task-файл.
