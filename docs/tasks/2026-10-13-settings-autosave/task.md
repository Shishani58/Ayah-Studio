# Автосохранение настроек

Цель: изменения применяются и сохраняются автоматически; нижняя панель удалена.
Скоуп: settings HTML/CSS/JS, прежний API и модель данных.
Прочитано: обработчики settings и API /api/settings, macos-settings/task.md,
STATUS.md; web-ui-ux ранее загружен в этой задаче.
Решения: последовательная запись изменений, немедленное применение селектов
и темы; короткая задержка записи текста, сброс задержки при закрытии.
Ошибки показываются и возвращают последнее сохранённое значение;
закрытие/Escape не отменяют успешные изменения.

Искусственная ошибка API возвращает подтверждённое значение и выводит ошибку.
