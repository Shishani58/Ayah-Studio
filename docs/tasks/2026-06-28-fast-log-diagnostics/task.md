# Fast log diagnostics

## Скоуп

Обогатить realtime/JSON-логи fast/auto-разметки данными, которые помогают понять:
лишние ли паузы, не слишком ли мало нейро-чтение, и не с неверного ли места
начинается окно. Алгоритм разметки и формат БД не менять.
