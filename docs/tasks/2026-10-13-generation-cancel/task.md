# Отмена текущего расчёта

Цель: кнопка остановки прерывает текущую суру, включая пословный режим.
Скоуп: отмена worker, inference, декодирования и CTC; сохранность уже записанных
меток и ручного ревью. Другие незакоммиченные изменения сохраняются.

Прочитаны: docs/project.md (пайплайн, модели, инварианты), релевантные записи
docs/STATUS.md (пословный режим и прежняя отмена между сурами).
Причина: _GenJob проверял Event только перед следующей сурой.
Решение: контекст отмены потока, проверки перед записью и между аятами,
прерывание ONNX RunOptions и дочернего runtime при ожидании ответа.

- [x] Регрессии отмены, сохранности и повторного запуска
- [x] Ruff / pytest
- [x] Документация

Блокеры: нет. Запущенный пользователем процесс использует прежний код;
изменение потребует перезапуска приложения.

Проверка: весь pytest — 399 passed, 7 skipped (2.77 с); Ruff surah_cutter/tests,
node --check app.js и git diff --check прошли. Отдельные регрессии подтверждают
отмену текущего аята до записи, сохранность verified/готовых слов, SSE cancelled,
освобождение lock, повторный запуск и перезагрузку мёртвого runtime-cache.
Blocking pipe проверен с настоящим дочерним процессом; ONNX — настоящий
RunOptions с mock session. Нативный inference моделей при отмене и WKWebView
не проверены. Готовый .app не пересобран.
