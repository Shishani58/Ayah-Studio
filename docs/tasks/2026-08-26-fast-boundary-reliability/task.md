# FAST: надёжность границ аятов

## Цель и scope

Консервативно усилить FAST forced alignment: подтверждать границы независимыми
сигналами, ограничивать неверные переходы вперёд, локально переобрабатывать
подозрительные окна и явно оставлять неразрешённые случаи на review. Формат
итоговой БД и правила merge не меняются.

## Исходное устройство и риск

- CTC локально задаёт onset и confidence; greedy CTC после паузы сопоставляется
  с началом ожидаемого аята.
- DSP/energy дают интервалы пауз, VAD уточняет только часть кандидатов; темп
  строится по взвешенной длине транслитерации и соседним speech-span.
- `_sequential_pause_match` сопоставляет паузы последовательно и пытается
  восстановить пропуски. Сложные повторяющиеся начала, короткие паузы и
  неправильно выбранный owner могут породить будущий match или продолжить
  ошибочную секцию.

## Решения

- Добавить минимальный независимый boundary-audit/repair слой после текущего
  сопоставления: CTC, pause/VAD, текст, длительность и соседний контекст.
- Автоматически менять только достаточным числом подтверждённые `auto`-границы;
  иначе записывать диагностическую причину и понижать confidence для review.
- Rollback ограничивать локальным окном; запретить непроверенный skip вперёд.
- Если rollback не восстановил весь интервал до future-якоря, сохранять якорь
  только как `deferred_future_anchor` для ограничения wasl-окна, а не как
  подтверждённый аят. Это не даёт перепутать будущую фразу с текущей и при этом
  не выбрасывает корректные правые якоря для локального CTC-восстановления.
- Если full-CTC подтверждает pause-backed repair, DSP edge внутри той же паузы
  уточняет её start/end только при сильной речи с обеих сторон и согласованной
  wave-геометрии. Для первого аята сильный CTC внутри второй половины
  intro-VAD-паузы имеет приоритет; в первой половине сохраняется VAD-граница.
- Пороги оформить именованными параметрами окружения рядом с существующими
  FAST-порогами. Без новых тяжёлых зависимостей.
