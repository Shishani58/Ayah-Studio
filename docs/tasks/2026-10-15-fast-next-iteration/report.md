# FAST: split первого ASR-слова — результат

Исправлена конкретная причина остановки Tiny77:7. Модель слышала «إن ما»,
а canonical содержит «إنما». Буквы не меняются: новый путь проверяет исходные
токены и полную различающую фразу минимум из двух целых канонических слов.
На свежем корпусе Tiny получила **18 дополнительных подтверждений**, включая
17 после устранённой остановки. Ошибки новых меток к эталону:2–447мс,
медиана42,5мс. Потерь и изменений прежних подтверждений нет, новых>500мс нет.
Это сравнение с эталоном, а не выполненное прослушивание всех новых границ.

## Принятое правило

- Только split первого обычного ASR-слова; первый canonical word>=3 букв.
- Все буквы должны совпасть; целый уникальный первый word разрешает
  конечное расширение той же паузы, но не подтверждение. Сильное
  противоречащее продолжение запрещает расширение.
- Proof требует минимум2 целых canonical words, точных концов исходных
  ASR-единиц и прежнего порога0,6 для ВСЕХ contributing selected tokens.
- Конкуренты получают тот же допуск сегментации: сравниваются буквенные
  prefixes каждого канонического word start, включая внутренние слова.
  Повтор первого prefix консервативно отклоняется; рефрены не получают обход.
- Alias/unsupported attribution отклоняются. Ledger сохраняет исходные units,
  probabilities и BPE ownership; proof — число source units/selected indices.
  Validator независимо пересчитывает proof. Никакой правки текста/букв.
- Split не даёт физического onset. Timestamp остаётся прежним DSP midpoint.
  Лимиты6с/65%/200%, порядок, пороги, FULL fallback не изменены.

До интеграции найдены аналоги:[split-discovery.json](split-discovery.json) —
единственный наблюдаемый split head в сохранённом Tiny/Base корпусе;
[canonical-segmentation-collisions.json](canonical-segmentation-collisions.json) —
все114 canonical текста,39«انما» openings и2099 openings с char-prefix rival,

отвергнуты. Пропущенные буквы не восстанавливаются.

Локальный опыт:[split-local.json](split-local.json),[анализ](split-local-analysis.json).
