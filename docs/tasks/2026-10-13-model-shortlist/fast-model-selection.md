# Модель для быстрого режима

Текущий выбор — Quran Phonetics INT8. Только она из четырёх подключена к
локальному FAST. Это временный рабочий выбор, а не победитель сравнения моделей.
FULL на 37 сурах: медиана 58 мс, p95 269 мс. Локальный FAST на том же наборе:
медиана 73.5 мс, p95 4465.85 мс, 107/564 ошибок >500 мс, 288/564 меток для
ревью. Время FAST 150.38 с на 3184.48 с записи, без загрузки и декодирования.
Нельзя переносить точность FULL или его время на FAST.

Для следующего сравнения: Quran Phonetics как база, Muaalem и FastConformer
Arabic как кандидаты. Whisper Large-v3 остаётся для полного расчёта; его
преимущество на коротких локальных фразах не проверялось.

Протокол отдельной задачи:

1. Один набор пауз DSP/VAD, одинаковые записи Шатри 78–114 и отдельные записи
   других чтецов для проверки переноса. Эталон читать только после расчёта.
2. Локальные окна: минимальная различающая фраза возле паузы. Расширять только
   при конкретной неоднозначности. Записывать каждый реальный inference-интервал;
   полный проход и покрытие всей суры последовательными окнами запрещены.
3. Адаптировать определения цели/головы для каждого кандидата. Не использовать
   фонетический словарь другой модели и не подменять канонические слова ASR.
   Фиксировать revision, preprocessing, флаги, лаг, read limits и hardware.
4. Измерять median/p95/max, ошибки >500 мс, неверные уверенные границы,
   долю неподтверждённых границ, latency и реально прочитанное аудио. Загрузку
   модели, decode и собственно поиск/чтение считать раздельно.
5. Выбирать по уменьшению грубых ошибок и неподтверждённых границ при соблюдении
   локального контракта и приемлемом времени. Неподтверждённое оставлять для
   ревью; победителя не назначать по FULL-замерам 112/114.

Новые адаптеры FAST этим изменением не реализованы. Текущие ограничения
не устранены сменой названия модели в настройках.
