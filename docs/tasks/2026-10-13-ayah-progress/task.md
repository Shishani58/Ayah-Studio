# Прогресс разметки по аятам

## Цель и scope
Перенести индикатор под статистику в шапке, показывать текущий аят и
каноническое число аятов, добавить видимый таймер для одиночного и пакетного
расчёта. Не менять результаты алгоритма, формат БД и ручную разметку.

## Прочитано
- AGENTS.md / CLAUDE.md, RTK.md — правила репозитория и команд.
- docs/project.md — инварианты, FAST, пути FULL/tiled/words.
- docs/STATUS.md (актуальные разделы) — прежняя навигация и отмена.
- web-ui-ux / better-layout — расположение, существующий стиль, адаптивность.

## Решения
- Структурированный callback текущего аята; SSE содержит общее количество
  аятов выбранных сур из quran_mushaf.db и текущую позицию.
- Прогресс отражает проход алгоритма, отдельно от сохранённой статистики.
  Подготовка остаётся на 0; 100% только после успешного завершения задания.
- Пословный режим считает аяты пословного прохода, не удваивает их при
  предварительном расчёте границ. FULL ждёт реальной проверки аятов;
  FAST сохраняет контракт локальных чтений.
- Таймер рядом со счётчиком; останавливается при результате/ошибке/отмене.
