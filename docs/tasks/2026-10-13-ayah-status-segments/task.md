# Компактные сегменты статуса аята

Цель: заменить громоздкий select цветными сегментами с подписями снизу.
Скоуп: существующий редактор начала, JS/CSS; API и статусы БД сохраняются.
Прочитано: web-ui-ux ранее в диалоге, текущие renderAyahList,
setAyahStatus/commitMarker, CSS popover и предыдущая задача статусов.
Решение: три кнопки с aria-pressed, цветной полосой и текстовой легендой;
активный сегмент обозначен галочкой, недоступные состояния отключены.
