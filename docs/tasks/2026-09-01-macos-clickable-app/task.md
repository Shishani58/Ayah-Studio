# macOS-приложение для запуска двойным кликом

## Цель

Собрать актуальный `Surah Cutter.app` для macOS, который открывается двойным
кликом в Finder и не требует запуска команд в терминале.

## Границы

- Обновить PyInstaller-описание с устаревшего Qt-интерфейса на текущий
  `webgui` (`pywebview` + локальный FastAPI).
- Включить в bundle данные Корана, статические файлы интерфейса, шрифт и
  необходимые ONNX-модели.
- Описать воспроизводимую локальную сборку и проверить готовый `.app`.

## Прочитано

- `docs/project.md` и `docs/STATUS.md` — текущее устройство и статус упаковки.
- `surah_cutter/webgui/launch.py` — фактическая точка входа.
- `docs/development/packaging.md`, `surah_cutter.spec`, CI — прежняя упаковка.

## Решение

Использовать PyInstaller `BUNDLE` на macOS. Данные, от которых зависят пути
рантайма, класть в корень bundle; web-статические файлы — рядом с пакетом
`surah_cutter.webgui`.

`surah_cutter.spec` исключён из общего правила `*.spec`, чтобы актуальная
конфигурация сборки хранилась в репозитории. Сгенерированные `.app` и `dist/`
по-прежнему исключены.
