# Обновление приложения из настроек

Цель: отдельный раздел обновлений в полном диалоге настроек; проверка сразу
скачивает релиз, явная кнопка закрывает приложение и запускает замену с откатом.
В текущем checkout прежнего пункта/механизма обновлений нет.

Прочитано: AGENTS/CLAUDE и RTK (правила), релевантные разделы project/STATUS
(desktop/настройки), build.yml/build_macos.py/package_windows.ps1/spec (форматы
релизов), launch.py (native bridge), web-ui-ux (существующий HTML интерфейс).

Решения: без новых зависимостей; GitHub Releases Shishani58/Ayah-Studio;
macOS DMG своей архитектуры и Windows x64 ZIP + обязательный SHA256.
Только frozen native desktop; source/browser объясняют недоступность.
Helper вне заменяемой папки ждёт завершения процесса, сохраняет старую версию,
заменяет и перезапускает. Установка во время расчёта запрещена.
Пользовательские БД/настройки не изменяются. Коммиты/публикация не входят в задачу.

Проверка: 40 pytest passed (test_app_updates, test_webgui_localization,
test_webgui_async), scoped Ruff, node --check app.js/updates.js и git diff --check.
Настоящий shell helper на временных каталогах проверяет ожидание PID, успешную
замену, отсутствие stage и отказ запуска с откатом. Запуск через open подменён.
Node проверяет состояния загрузки/готовности/повтора/ошибки/установки и сохранение
блокировки кнопок; browser подтверждает доступность раздела и disabled source state.
Проверены имена актуальных release assets GitHub v0.3.1: соответствуют селектору.

Ограничения: полноценный frozen .app/Windows install, Windows PowerShell helper,
Gatekeeper и права в Applications/Program Files на реальных машинах не проверены.
Повышение привилегий не выполняется: нужна доступная для записи папка приложения.
Source/browser не могут заменить установленную версию. Первый выпуск с этой
функцией нужно установить обычным способом. Публикация/сборка не выполнялись.
Резервная копия сохраняется в .ayah-update-*/previous рядом с приложением,
лог helper — install.log; автоматическая проверка здоровья после запуска отсутствует.
Неиспользованная подготовка очищается при штатном выходе; после установки
резервная копия сохраняется. Отдельные успешные обновления сохраняют свои копии.
