## Находки и решения

1. **P1 — экспорт поверх исходного проекта уничтожает служебные данные.**
   `data/export_db.py:68–73`: исходная БД читается, затем destination удаляется
   без проверки совпадения путей. API передаёт выбранный путь напрямую.
   Воспроизведено на временном проекте с 6236 строками: после `export_db(p, p)`
   остаются только `timings` и `db_version`, исчезают `review_meta` и
   `edit_history`. Нужны запрет совпадающего файла и атомарная запись экспорта.
2. **P1 — strict-экспорт не проверяет корректность состава и времени.**
   `data/export_db.py:53–65` проверяет только суммарные количества и дубли.
   Воспроизведён успешный экспорт отрицательного/немонотонного времени, а
   также замены 1:7 на несуществующий 1:999 при сохранении 6236/114.
   Нужны точный набор аятов из Quran DB, проверка времени и регрессионные тесты.
3. **P1 — смена проекта во время генерации смешивает источники.**
   `webgui/server.py:69–82,153–165`: worker открывает БД один раз, но аудио
   читает из изменяемого STATE на каждой суре; open_project не блокируется.
   Воспроизведено с подменённым aligner: прочитаны A/113.mp3 и B/114.mp3,
   оба результата записаны в A.db. Нужен неизменный контекст задания и/или
   запрет смены проекта до завершения; логам нужен тот же контекст.
4. **P2 — продолжение пропускает частично размеченные суры.**
   `webgui/server.py:771–785` считает любую строку timings признаком завершения.
   Воспроизведено: ручная метка 114:1 делает суру «готовой» для only_missing,
   хотя отсутствуют пять аятов. `classify_status` также относит частичную
   разметку к processed. Нужна проверка полного состава суры в сервере и UI.
5. **P1 для релиза — чистая CI-сборка не обеспечена моделями.**
   `.github/workflows/build.yml:34–41` сразу запускает PyInstaller после pip;
   `surah_cutter.spec:47–57` требует локальные ONNX и sidecar-файлы, но
   `git ls-files models` пуст. Шага получения моделей нет. Нужна доставка
   зафиксированных артефактов с хешами до сборки. Вывод по коду и tracked-файлам;
   удалённый CI в этом ревью не запускался. В workflow также нет pytest/ruff.
