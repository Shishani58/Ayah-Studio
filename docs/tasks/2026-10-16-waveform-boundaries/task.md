# Уточнение разрезов FULL по аудиосигналу

## Цель и скоуп
По уточнению пользователя исследовать и применить уточнение тишины/волны вместо
добавленной автоматической загрузки второй модели для поздних разрезов FULL.
Основной FULL определяет последовательность аятов; локальный DSP выбирает
разрез. Не менять FAST, текст/схему БД, ручные метки и другие модели.
Сохранить чужие незавершённые изменения, не коммитить.

## Evidence
Прочитаны AGENTS/CLAUDE и RTK, FULL-раздел docs/project.md, отчёт/измерения
full-transition-refinement. Код full_pause_center, candidates._refine_pause_edges:
noise/speech percentile зависит от crop; выбор самого длинного низкого run
может переставить детектор с межаятной паузы на внутренний тихий участок слова.
В UI волна — огибающая тех же PCM samples, не отдельная модель/источник.

основного FULL. DSP/внешняя БД не заменяют независимое слуховое принятие.
