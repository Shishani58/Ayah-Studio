# Анимации и постепенная загрузка волны

Цель: плавные модальные окна и показ готовых участков аудиоволны до конца декода.
Скоуп: web GUI; без изменений разметки, БД и alignment.
Прочитано: AGENTS.md/CLAUDE.md, RTK.md; docs/STATUS.md и задача progressive-review
(независимая загрузка); docs/project.md (инварианты); animate и web-ui-ux.
Решения: bundled ffmpeg, поток SSE, отмена при смене экрана/суры;
opacity для новых участков, короткие transform/opacity для модальных окон.
Reduced motion и клавиатура учитываются; новые зависимости не нужны.
Существующие незакоммиченные изменения сохраняются.

Метаданные аудио дают предварительную длительность и выбирают разрешение
около прежних 1600–65536 участков; точный конец и нормализация определяются PCM.
Поток не сохраняет PCM целиком. Ошибки имеют повтор, отключение клиента
останавливает дочерний процесс, закрытие во время входа/повторное открытие
отменяет предыдущую анимацию. Модальные окна 220/200 мс, панели 180 мс,
волна — opacity 180 мс; reduced motion без transform, клавиатура мгновенно.
