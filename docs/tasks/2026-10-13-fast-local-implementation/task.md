# Возврат локального FAST

Цель: удалить полное акустическое чтение и скрытую эскалацию; сохранить
проверки границ, FULL, текст и ручные данные.
Прочитано: AGENTS.md/CLAUDE.md, RTK.md, docs/project.md,
fast-local-contract/task.md, alignment-reliability/task.md и benchmark.py;
история 3d36fbf^ (локальный cache), 3d36fbf и 1f791be.
Решения: локальный cache с точным учётом inference; жёсткий предел отдельного
чтения и объединённого покрытия. Широкие wasl-блоки остаются для ревью.
Проверка: regression pytest, Ruff, diff-check; реальные Шатри 78–114,
reference только после вычисления меток. Чужие изменения не трогаются.
Чек-лист: реализация, trace, тесты, корпус, документация.
Блокеры: пока нет; качество локального режима подлежит измерению.

## Реализация и результат

- Удалены full_emissions и оба tiled fallback из FAST. FULL не изменён этой
  задачей. Старые batch=1, onset-check 112/114, DSP/VAD intro и micro-паузы,
  CTC completeness, геометрия и структурные проверки сохранены.
- Локальный cache восстановлен по идее 3d36fbf^, без отката всего файла.
  `fast_reads.py` централизует реальное чтение: до 6 с, union <=65%,
  суммарный вход <=200%. Лимиты консервативные, не обещают сохранения качества.
- Начало читается после intro-паузы, а не с басмалой от начала записи.
  Паузы сначала читаются на 1.3 с речи; текстовая неоднозначность сама по себе
  не расширяет каждую постороннюю паузу. Расширение требует слабого,
  но правдоподобного совпадения префикса. Длинный wasl-блок не выравнивается.
- `model_reads`/`acoustic_reads` содержат реальные вызовы и абсолютные интервалы,
  `alignment_reads` — CTC-решения/cache-срезы. Учтены sum и union, отказы и
  review_required_ayahs. При отказе/каскаде confidence=0; неподтверждённый prior
  обозначен `unresolved_local`, не выдаётся за доказанный wasl-start.
- Валидатор tools/bench_fast.py принимает unresolved только при confidence=0
  и явном review-флаге. Подтверждённые pause-owner по-прежнему строго в центре.

## Проверка на Шатри

Итоговый повторный прогон 78–114, 564 аята, без параллельных модельных тестов:
150.38 с (VAD, inference, matcher; без загрузки модели и декодирования).
1650 реальных вызовов; вход с повторениями 4469.98 с на 3184.48 с записи;
union 1938.54 с = 60.88%. Каждое окно <=6 с, каждая сура <=65%,
whole-sura inference и FULL/tiled fallback отсутствуют. Полный порядок,
число аятов и pause-контракт — без нарушений.

288/564 меток явно требуют ревью. Ещё 6 ошибок >500 ms имеют ненулевую
confidence: 78:28 (554), 80:37 (672), 84:10 (903), 87:3 (2955),

Это заметное ухудшение относительно исторического single-pass аудита
(median 54 ms, p95 214.85 ms, >500=12); его полный акустический проход теперь
запрещён. Для длинных wasl и повторяющихся начал нужны дополнительные
локальные методы; fallback не возвращён ради хороших цифр. Скорость
измерена, ускорение относительно FULL этим прогоном не доказано.
