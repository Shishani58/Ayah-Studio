# Пословная разметка

Цель: режим «По словам» рядом с быстрым/полным, расчёт всех слов суры и
проверка/правка по слуху. Экспорт аятной БД не меняется.

Прочитаны: docs/project.md (пайплайн, басмала, инварианты), docs/STATUS.md
(web-ревью); web-ui-ux (существующий HTML/JS интерфейс).

## Итоговые решения

- Один список ревью: полный/быстрый режим показывают аяты целиком; пословный
  заменяет этот вид. Каждый аят — отдельная группа с горизонтальными карточками
  слов в каноническом RTL-порядке; редактор времени находится под словом.
  Отдельной секции слов рядом с обычной разметкой нет.
- Поля переключаются между секундами (3 знака) и целыми миллисекундами.
  Enter/blur сохраняют; переключение единиц не изменяет тайм-код. Обработчики
  сохраняют единицы, в которых было создано поле, чтобы его blur при смене
  представления не интерпретировал секунды как миллисекунды.
- Клик по слову сразу проигрывает его отрезок. Общие Play/стрелки работают
  со словами. Подсветка/масштаб волны относятся к выбранному слову. Остановка
  запланирована отдельным таймером с учётом скорости и дублируется timeupdate;
  последний отрезок ограничен концом своего аята.
- Расчёт работает для всей суры/всех сур. Имеющиеся полные аятные границы
  сохраняются; недостающие строятся FAST. Возобновление проверяет набор слов.
  Ошибка одного аята видна в логе и не мешает остальным. Настройка words
  сохраняется и синхронизируется между экранами.
- Слова/порядок только из quran_mushaf.db; транслитерация по исходным индексам
  слов суры. Неполный CTC-путь отклоняется, равномерной подстановки нет.
- word_timings и word_edit_history — служебные таблицы проекта. Ручные/verified
  слова защищены; источник хранит ONNX/CTC, модель и компенсацию задержки.
  Снимок границ аята позволяет помечать устаревшие метки, не удаляя их.
  Все правки проверяют соседей/границы/контекст проекта до записи.
