# Fast pause match

## Скоуп

Исправить fast-сопоставление пауз с аятами: читать аудио от конца паузы,
не принимать слабые fuzzy-совпадения как якоря, логировать почему пауза
выбрана или отброшена. Формат БД не менять.

## Решения

- Greedy decode паузы стартует около правого края паузы, а не из её центра.
- Глобальный DP заменён локальным выбором паузы около ожидаемой зоны: дальние
  случайные совпадения больше не должны тянуть всю цепочку.
- Длинные wasl-серии не выравнивать целиком в fast: это превращает режим в
  медленный full-подобный прогон.
- Для диагностики сохранять лучшую паузу около expected и причину отбрасывания.
