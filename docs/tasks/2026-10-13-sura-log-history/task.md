# Список логов суры

Цель: иконка логов, список всех сохранённых логов выбранной суры и просмотр
содержимого выбранного лога в существующем модальном окне.
Прочитано: docs/project.md (хранение), docs/STATUS.md, _save_sura_log,
маршруты/API, существующий dialog и live-log.
Решение: читать пары .log/.json из папки текущего проекта, показывать дату,
режим и полные данные; текущий live-log доступен отдельным пунктом.
Формат записи не меняется: существующее хранение оставляет последний лог
каждого режима. Удалённые/перезаписанные логи восстановить нельзя.
