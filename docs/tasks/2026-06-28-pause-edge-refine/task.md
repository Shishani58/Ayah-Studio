# Задача: уточнить границы найденных пауз

## Цель

Паузы в pause/draft pipeline визуально и по слуху оказываются сдвинуты: energy
detector ищет кандидатов по сглаженному RMS, из-за чего края паузы разъезжаются
наружу и `pause.end_ms` может попадать позже реального начала следующего аята.

## Скоуп

- `surah_cutter/core/candidates.py`: уточнять края кандидата по исходному
  несглаженному RMS после первичного поиска.
- `tests/test_candidates.py`: зафиксировать, что короткая слабая пауза не
  расширяется сглаживанием.
- Без изменения формата БД, текста Корана и GUI/API-контракта.

## Прочитанные доки

- `docs/STATUS.md`: текущая схема pause pipeline и место weak-pass.
- `docs/tasks/2026-06-27-pause-recall/task.md`: предыдущее решение по weak-pass.

## Решения

- Оставить сглаженный RMS для recall кандидатов.
- Для итогового `Pause(start_ms, end_ms)` искать внутри окрестности кандидата
  самый длинный contiguous raw-low участок.
- Если raw-уточнение не даёт паузу нужной длины, кандидат отбрасывается: это
  защищает от пауз, появившихся только из-за размытия сглаживанием.
