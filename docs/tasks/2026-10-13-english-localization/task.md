# Английская локализация

Цель: русский/английский интерфейс, смена языка в настройках, язык системы
при первом запуске с сохранением ручного выбора.
Скоуп: основной HTML/JS GUI, настройки и API; арабский текст и тайм-коды неизменны.
Прочитано: STATUS.md (текущее состояние), settings-autosave/task.md (сохранение
и rollback), settings.py, launch.py, соответствующие API и интерфейс.
Skill: web-ui-ux — сохранить существующие компоненты и проверить обе локали.
Решения: ru для русского языка системы, en для остальных; язык общий для
приложения, сохраняется в settings.json. Без зависимостей в приложении.
Технические записи диагностических логов сохраняются в исходном виде.

Изменённые файлы:
- webgui/settings.py: определение языка ОС и сохранение начального выбора.
- webgui/server.py: language в API, проверка ru/en, язык HTML; recording_is_default
  отделяет системную заглушку от пользовательского названия без смены прежнего API.
- webgui/static/i18n.js: каталог, локализация статических узлов и явных шаблонов.
  Данные подставляются после перевода шаблона, арабский текст не сканируется.
- webgui/static/app.js, models.js, index.html: динамические переводы,
  переключатель с прежней очередью автосохранения и rollback.
- webgui/static/sura-names.js: английские транслитерации из Tanzil metadata.
- tests/test_webgui_localization.py: язык ОС (native API с mocks), persistence,
  валидация, сохранение, отказ записи; Node-проверка каталога, шаблонов,
  неизменности арабского текста и пользовательских данных.

Проверка: pytest — 425 passed, 7 skipped; Ruff, четыре node --check,
git diff --check, совпадение AGENTS.md/CLAUDE.md. Каталог покрывает весь
статический текст HTML и явные русские сообщения JS, включая новые строки
прогресса из параллельной задачи. Node нужен только для проверки JS в тестах,
не для работы приложения; новых runtime-зависимостей нет.
In-app браузер (WKWebView): en/ru, light/dark, 320/390/1280 px без overflow;
настройки, модели и справка, проекты с русскими пользовательскими именами,
редакторы аятов и слов, сохранение/reload, быстрые смены, искусственный отказ
записи с возвратом en и английской ошибкой, Escape/возврат фокуса.
Тестовая SQLite с auto/edited/verified и словами осталась побайтово неизменной
(SHA-256) после переключений. [Снимок настроек](settings-en.jpg).

При параллельном изменении app.js устарели позиции подготовленного скрипта.
Обратная обработка вставок и повторный разбор актуального AST восстановили
корректный JS без удаления прогресса/таймера соседней задачи; проверено в
общем дереве. Согласование чатов явно разрешено пользователем.
