Разметка аудио Корана
  1. Папка аудио — выберите папку, где файлы названы по номеру суры (001.mp3 … 114.mp3). Один файл = одна сура.
  2. Проект — выберите/создайте файл .db: в нём копится разметка. Можно вернуться и продолжить позже.
  3. Сгенерировать — программа сама расставит начало каждого аята — это черновик для проверки на слух.
  4. Проверить — откройте суру: слушайте, смотрите на волну, при необходимости двигайте границы и отмечайте «проверено».
  5. Экспорт — когда все 114 сур готовы, выгрузите чистую .db.
